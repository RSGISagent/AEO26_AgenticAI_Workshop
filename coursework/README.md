# Coursework — coming soon

Workshop notebooks, sandbox exercises and case-study materials will be published here **before 9 November 2026**.

Planned modules (draft, subject to change):

1. **Vibe coding** — build a working geospatial analysis from a plain-language prompt
2. **Agentic tool use** — chain tools (search, code execution, files, APIs) over open Australian environmental data
3. **Autonomous agents in sandboxes** — set a goal, walk away, then verify and audit the agent's work

All case studies use remote sensing and GIS in an Australian environmental context, built on open data: Digital Earth Australia, Copernicus/Sentinel, Geoscience Australia, TERN and the Atlas of Living Australia.

**In the meantime:** complete the [prerequisites](../README.md#-before-you-arrive--the-only-two-prerequisites) and, if you like, the [free pre-workshop training](../README.md#-pre-workshop-learning-optional-free).
